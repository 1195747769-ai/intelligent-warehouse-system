
# Baphalane Materials Ledger · 本地试用版

面向海外新能源 EPC 项目的轻量物资台账。当前版本为单机试用版，支持中文和英文界面、厂家到货 Excel 识别入库、库存总览、批量出库、流水追溯、单据打印与管理员删除。

## 启动

安装 Python 3.11 或更高版本，运行 pip install -r requirements.txt，然后双击 启动系统.cmd，访问 http://127.0.0.1:8765。

## 边界

当前不接入云端，不上传数据库和厂家原始文件。业务资料请保存在本机；多人协作和网络认证留到后续版本。

详见 宣传文案.md 和 CHANGELOG.md。
