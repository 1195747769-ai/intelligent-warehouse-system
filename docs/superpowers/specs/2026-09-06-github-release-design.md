# GitHub 公开发布设计

## 目标

把当前单机物资管理试用版整理成可下载、可运行、可理解的公开仓库，同时不把实际库存、厂家文件、备份、日志或管理员密码发布出去。

## 范围

- 仓库根目录使用 `outputs/materials-app` 的程序文件。
- 保留本地 SQLite 和现有单机启动方式，不引入云端、账号、采购系统或多人协作。
- 公开 README、更新记录、运行依赖、MIT 许可证和中英文宣传文案。
- `.gitignore` 排除 `data/`、数据库、日志、备份和内部验收报告。
- 首个版本标记为 `v0.1.0`，发布说明明确当前边界。

## 公开功能叙述

1. Excel 入库：自动选择工作表、识别中英文表头、保留合并箱号、备注和箱内子项。
2. 库存：按 A1–A16 标段、到货批次、箱号和库位逐层查看，并支持筛选与排序。
3. 出库：按物资搜索、填写数量，自动拆分到多个批次和库位并生成独立出库单。
4. 删除：独立“删除办理”页面，管理员输入密码后批量删除整张误录单据并回滚库存；后续流水、设计基准和冲销单不得硬删除。
5. 追溯：流水总账、作废/冲销、打印单据和本地备份。

## 质量门槛

- `python -m py_compile server.py`
- `node --check static/app.js`
- `python -m unittest test_ledger.py -q`
- 浏览器检查九个入口、删除办理、物资总表孤立记录清理、中英文切换和本机服务可访问。

## 发布步骤

1. 只提交白名单代码和公开文档，确认数据库、日志、密码文件未被追踪。
2. 创建首个 Git 提交并标记 `v0.1.0`。
3. 推送到 GitHub 仓库 `baphalane-materials-ledger`。
4. 发布页使用 `宣传文案.md` 的中文和英文短文案，并在正文中保留单机边界。
